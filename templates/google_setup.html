Connect Google OAuth

1. Create the client

Open Google Cloud Console, create or select a project, configure the OAuth consent screen, then create an OAuth 2.0 Client ID with application type Web application.

Open Google Cloud credentials

2. Register this redirect URI

It must match exactly:

{{ redirect_uri }}

3. Update the local .env

GOOGLE_CLIENT_ID=your_client_id
GOOGLE_CLIENT_SECRET=your_client_secret
GOOGLE_REDIRECT_URI={{ redirect_uri }}

Do not commit or share the client secret.

4. Restart Flask

Ctrl+C
python app.py
Return to my account
