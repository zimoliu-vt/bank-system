Bank System API

Card endpoints use X-API-Key. Management endpoints use X-Admin-Key.

Demo only. This project is not a real bank or payment processor and should not hold real financial data.
GET/api/cards/<id>

Return the authenticated card and its recent transactions.

curl -H "X-API-Key: bank_card_..." http://127.0.0.1:2501/api/cards/1
POST/api/cards/<id>/transactions

Create a deposit or withdrawal for the authenticated card.

curl -X POST http://127.0.0.1:2501/api/cards/1/transactions \
  -H "Content-Type: application/json" \
  -H "X-API-Key: bank_card_..." \
  -d '{"type":"deposit","amount":25.50,"description":"Allowance"}'
POST/api/cards/<id>/payments

Pay another active card in the same currency. Authenticate with the sender's card key.

curl -X POST http://127.0.0.1:2501/api/cards/1/payments \
  -H "Content-Type: application/json" \
  -H "X-API-Key: bank_card_..." \
  -d '{"to_card_id":2,"amount":12.50,"description":"Lunch"}'
POST/admin/cards

Create a card. Its response contains the API key exactly once.

curl -X POST http://127.0.0.1:2501/admin/cards \
  -H "Content-Type: application/json" \
  -H "X-Admin-Key: YOUR_ADMIN_KEY" \
  -d '{"holder":"Alex Tan","label":"Everyday","initial_balance":100,"currency":"SGD"}'
POST/admin/cards/<id>/replace-key

Invalidate the previous card key and return a replacement once.
