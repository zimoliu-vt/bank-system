API DOCUMENTATION

Bank System API

User payments require a login session created with a card number and password. Management endpoints use X-Admin-Key; lower-level card endpoints use X-API-Key.

Demo only. This project is not a real bank or payment processor and should not hold real financial data.
POST/api/auth/login

Log in with the full card number and password. Retain the returned session cookie and CSRF token.

curl -c session.txt -X POST http://127.0.0.1:2501/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"card_number":"40000000","password":"your-password"}'
GET/api/account

Return the selected card, its transaction history, and every card linked to the same person.

curl -b session.txt http://127.0.0.1:2501/api/account
POST/api/account/select-card

Switch the logged-in session to another card linked to the same person. Requires the session CSRF token.

curl -b session.txt -X POST http://127.0.0.1:2501/api/account/select-card \
  -H "Content-Type: application/json" \
  -H "X-CSRF-Token: TOKEN_FROM_LOGIN" \
  -d '{"card_id":2}'
POST/api/payments

Send money from the logged-in card using either recipient with a Card ID or full 8-digit card number. The older to_card_id field remains supported. Use the csrf_token returned by login. The recipient keeps the original currency as a separate balance; no exchange occurs.

curl -b session.txt -X POST http://127.0.0.1:2501/api/payments \
  -H "Content-Type: application/json" \
  -H "X-CSRF-Token: TOKEN_FROM_LOGIN" \
  -d '{"recipient":"44808087","currency":"SGD","amount":12.50,"description":"Lunch"}'
GET/api/exchange/quote

Preview a reference-rate exchange between the logged-in user's own currency balances.

curl -b session.txt "http://127.0.0.1:2501/api/exchange/quote?from=SGD&to=USD&amount=25"
POST/api/exchange

Re-fetch the current quote and exchange money inside the logged-in account. Requires the session CSRF token.

GET/api/cards/<id>

Card-key access for authenticated integrations.

curl -H "X-API-Key: bank_card_..." http://127.0.0.1:2501/api/cards/1
POST/admin/cards

Create a card. Its response contains the card API key exactly once. To link a same-name card to an existing person, include that person's existing integer linked_card_id.

{"holder":"Alex Tan","label":"Travel","currency":"USD","initial_balance":0,"linked_card_id":1}
PUT/admin/cards/<id>/login

Set or reset the password used with that card's displayed number.

DELETE/admin/cards/<id>

Permanently delete a zero-balance card.
